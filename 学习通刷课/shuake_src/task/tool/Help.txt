一、浏览器选择相关

  1.问：在设置页面中，浏览器如何选择？
    答：支持三种浏览器：edge、chrome、firefox。选择后点击"选择文件"按钮，选择与浏览器版本匹配的驱动（edgedriver / chromedriver / geckodriver）。

  2.问：如何查看浏览器版本号？
    答：打开浏览器，进入"设置-关于"即可查看版本号。请下载与浏览器主版本号一致的驱动。

  3.问：浏览器驱动在哪里下载？
    答：
    - Chrome 驱动：https://googlechromelabs.github.io/chrome-for-testing/
    - Edge 驱动：https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
    - Firefox 驱动（geckodriver）：https://github.com/mozilla/geckodriver/releases

二、驱动地址相关

  1.问：驱动地址是什么？
    答：驱动的地址不是浏览器安装地址，而是下载的驱动 exe 文件的路径。

  2.问：驱动地址如何配置？
    答：在设置页面点击"选择文件"，选中所下载驱动的 exe 文件即可。

三、API 设置相关

  1.问：API Key 怎么填写？
    答：在"高级设置"中填写你的 API Key。支持任意 OpenAI 兼容接口（如 DeepSeek、OpenRouter、本地 vLLM 等），不再限制必须以 sk- 开头。

  2.问：API 地址怎么填写？
    答：填写接口的 base URL，例如默认的 https://api.deepseek.com 或自定义中转地址。留空则使用默认地址。

  3.问：模型名怎么填写？
    答：可留空。留空时程序会自动向 API 接口请求模型列表，并优先选用对话/聊天类模型；也可以手动指定模型名（需确保该模型在你的 API 中可用）。

四、其他设置相关

  1.问：字体和信息设置有什么要求？
    答：字体根据自己的喜好设置，建议开启"窗口置顶"。课程名称要完整、一字不差地从学习通复制。

  2.问：刷题怎么设置？
    答：可选择"DeepSeek AI"（实际为任意配置的 API）、"随机答题"或"不刷题"。使用 AI 答题需先填好 API Key。

  3.问：倍速应当如何设置？
    答：建议设置为 2 倍速，过高可能会清空已完成的任务点。若在刷课途中想切换倍速，需要重新启动程序。

五、程序相关

  1.问：点击启动程序没有反应怎么办？
    答：确认驱动路径与浏览器版本匹配，并确保浏览器驱动没有过期。若仍无反应，可关闭程序后以管理员身份重新运行。

  2.问：如果选择了不刷题，启动程序后会怎样？
    答：会自动打开浏览器登录学习通并选择课程，随后跳过测验任务。若报错，可在"报错日志"页面查看。

  3.问：出现无法加载扩展怎么办？
    答：请检查浏览器与驱动版本是否一致。若一致仍报错，可尝试更换浏览器（另需下载对应驱动）。

六、其他问题相关

  1.问：还有其他问题怎么办？
    答：可以将报错日志页面中的内容保存下来，自行排查或根据提示修正配置。
